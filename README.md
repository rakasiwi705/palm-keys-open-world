# Coral Keys — an original open-world crime game

Coral Keys is an original open-world crime game set in Coral Keys, a sun-soaked tropical coastal town. It was built for the [Make GTA 6 bounty](https://make.fun/bounty/gta6-01) on make.fun. Every name, character, vehicle, story, and asset in this game is original.

## How to play

Open `game/index.html` in desktop Chrome, or serve the game locally:

```sh
node serve.ts
```

then open http://localhost:8080.

## Controls

- **WASD** — walk / drive
- **E** — enter / exit a car
- **F** — shoot
- **P** — pause
- **Q** — save
- **M** — mute
- **N** — new game

## Features

- A city to explore on foot and by car
- Traffic and pedestrians
- Cars to steal and drive
- Wanted level and police who respond to it
- Three story missions
- Combat
- HUD with a minimap
- Start screen and save/load
